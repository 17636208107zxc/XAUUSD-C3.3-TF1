# C3.2-B1 → C3.3-TF1：可核实变化

对照来源是本机当前 C3.3-TF1 主 EA、其同版 Include 与 MT5 目录内的 C32B 主 EA。以下只列可由源码佐证的变化；这不是逐行差异报告。

| 项目 | C32B | C3.3-TF1 |
|---|---|---|
| 普通逆势战术 | 根据战术条件及历史配额计算可用性 | 在 M15 更新处将 BUY/SELL 战术逆势许可和配额可用性直接置为 `false`；主路径定位 Pure Trend |
| M15 启动历史 | 当前比对主文件未见 C33 式启动回放入口 | `V3109C33WarmStartM15Trend()` 回放 400 个已闭合 M15 节点 |
| Early Trend | 当前比对主文件未见 C33 式 Early Gate 调用 | M15 状态更新后调用 `V3109C33ApplyEarlyTrendGate()` |
| M5 趋势参与 | 保留此前选路 | C33 主文件新增独立多/空 Compression Break 分支，并保留原有选路入口 |
| 默认单笔风险 | `InpRiskPercent=0.5` | 仍为 `0.5` |
| 分段退出 | 1R/2R 相关输入存在 | C33 默认 `1R/50%`、保本、`2R/余仓`；未发现此组默认值在两版主文件中变化 |

同版 C33 头文件现已找到：`TradeSlotPolicy.mqh` 明确定义三槽与总初始风险 1.5%；`M15EarlyTrend.mqh` 将 Early 入场限制为尚无已占槽位；多空交易计划在有有效结构目标但不足 2R 时拒绝，无目标时不触发该项拒绝。M5 EMA Recovery 和 Compression Break 的实现见各自头文件；本记录不把每一处内部变化都归因于 C3.3，除非已与 C32B 逐项比较。

本文仅做版本事实记录，不修改源码或参数。
